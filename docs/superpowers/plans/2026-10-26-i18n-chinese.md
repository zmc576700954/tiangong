# 全中文界面体系（i18n）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 BizGraph 引入一套轻量 i18n 层，让渲染进程界面与 Electron 原生菜单全部呈现中文，并可在设置面板一键切换中文 / English。

**Architecture:** 自建 `src/shared/i18n/` 共享层（类型 + 按域拆分的 zh/en 资源 + 核心 API），主进程与渲染进程各自打包一份模块实例、通过新增的 `locale:changed` 推送通道同步语言。渲染进程用 React context 提供响应式翻译，store / toast 等非 React 代码用共享层导出的模块级 `t()`。持久化落在 `settings.json` 的 `locale` 字段，存量数据零迁移。

**Tech Stack:** TypeScript（strict）、Electron 33、React 19、Zustand、Tailwind + shadcn/ui、Vitest（node 环境，渲染层用例逐文件加 `// @vitest-environment jsdom` pragma）、零新增第三方依赖。

**Spec:** `docs/superpowers/specs/2026-10-26-i18n-chinese-design.md` —— 实施本计划前请先读该设计文档；计划与 spec 冲突时以 spec 为准。

## Global Constraints

- **零新增依赖**——不得引入 `i18next`、`react-i18next` 或任何 npm 包；只用仓库现有依赖。
- **存储值一律不变**——节点 `type`/`status`、图 `graphType`、`chat_threads.title`、图名 `graphs.name` 全部保持现有值；只翻译展示层。
- **中文一栏沿用现有 UI 原文**——迁移 `src/shared/constants.ts` 的标签表时，中文值逐字保留（业务模块 / 业务流程 / 功能点 / BUG点 / 待测试 / 待验收 / 占位 / 已上线场景 / 开发场景），不得改写措辞。
- **用户内容不译**——wiki 正文、recipe YAML 的 name/description/`inputs_schema[].label`、节点标题、会话消息正文、项目名、数据库里已存的图名。
- **保留英文的术语**——Claude Code、Codex、OpenCode、Cline、Kilo Code、Kimi Code、CodeBuddy、Qoder、Qwen Code、Cursor、Agent、Subagent、Agent CLI、Wiki、MCP、API Key、JSON、YAML、Shift+Enter。
- **不新增 invoke 型 IPC 通道**——只允许新增 1 条主→渲染的推送通道 `locale:changed`；`settings:read` / `settings:write` 复用现有通道。
- **不触碰 CLAUDE.md 的边界约定**——不改 Agent CLI 认证、system prompt、tool schema、ScopeGuard 语义、IPC 路径校验。
- **共享层双实例**——`src/shared/i18n/` 会被分别打包进主进程与渲染进程，运行时是两份独立实例；跨进程只能经 `locale:changed` 推送，代码里不得假设主进程的 `setLocale()` 能影响渲染进程。
- **原生 ABI 冲突**——`better-sqlite3` 同一时刻只能服务一种 ABI：跑 Vitest 前需 `npm rebuild better-sqlite3`（Node ABI 115），跑 Electron 应用前需 `npx electron-builder install-app-deps`（Electron ABI 130）。**每个任务跑完测试后都要切回 Electron ABI**，否则后续 `npm run dev` 会崩。

## Review Focus

以下五类是 spec 隐含、但没有哪条任务的自带用例直接覆盖、最可能真正咬人的输入。每个任务必须补上对应测试。

1. **英文 locale 下某个 key 在 `en` 里缺项**——界面必须显示中文兜底，**不能**显示裸 key `projects.title` 之类。→ Task 1 补测试
2. **用户在窗口 A 切换语言，窗口 B 必须跟随**——单窗口应用看不出问题，多窗口才会暴露。→ Task 4 补测试
3. **React 组件之外（Zustand store、`lib/toast.tsx`）的文案**——store 调不了 hook，模块级 `t()` 的 locale 必须与 Provider 一致，否则 toast 会显示错语言。→ Task 4 补测试
4. **用户自己命名的会话标题**——只有默认标题该被译成「新会话」并参与首条消息自动改名；用户命名的标题必须原样显示且不被改写。→ Task 8 补测试
5. **不以已知后缀结尾的图名**（用户自建图、从源项目派生的图）——`localizeGraphName()` 必须原样返回，不得截断或误替换。→ Task 8 补测试

```ts
    setLocale('zh-CN')

    expect(tRaw('totally.unknown.key')).toBe('totally.unknown.key')

  it('interpolates {name} placeholders', () => {

  it('leaves unknown placeholders untouched', () => {

  it('defaults to zh-CN', () => {
    expect(getLocale()).toBe('zh-CN')

  it('notifies subscribers on change and stops after unsubscribe', () => {
    const listener = vi.fn()

    setLocale('en-US')

    expect(listener).not.toHaveBeenCalled()
    unsubscribe()
  })
```

- [ ] **Step 5: 实现 `src/shared/i18n/index.ts`**

模块状态与四个状态函数（**行为已由 Step 1 的用例钉死**，实现照此语义）：

```ts
let currentLocale: Locale = DEFAULT_LOCALE
const listeners = new Set<(locale: Locale) => void>()

export function getLocale(): Locale
export function setLocale(locale: Locale): void   // 相同 locale 不通知
export function subscribeLocale(listener: (locale: Locale) => void): () => void  // 返回退订函数
```

三个必须做对的语义点：

1. **查找顺序**：`resources[currentLocale][key]` → `resources[DEFAULT_LOCALE][key]`（中文兜底）→ `key` 本身（并在 dev 打 `console.warn`）。**不能是「当前 → 英文 → key」**——那会让英文界面下漏翻的 key 显示成裸 key `projects.title`。
2. **插值**：`{name}` 占位符替换成 `vars.name`；`vars` 里没有的占位符**原样保留**（不替换成 `undefined`）。
3. **两套 API**：`t(key: TranslationKey, vars?)` 严格（key 写错编译报错）、`tRaw(key: string, vars?)` 宽松（动态 key，命中不到时 warn）。`t` 内部转调 `tRaw` 即可。

```ts
export function tRaw(key: string, vars?: Record<string, string | number>): string
export function t(key: TranslationKey, vars?: Record<string, string | number>): string
```

类型安全的动态查表（**禁止用模板拼接 key**——那会退回 `tRaw` 丢掉编译期检查）：

```ts
const NODE_TYPE_KEYS: Record<NodeType, TranslationKey> = {

  module: 'nodeType.module',
  process: 'nodeType.process',
  feature: 'nodeType.feature',

const NODE_STATUS_KEYS: Record<NodeStatus, TranslationKey> = {
```

在 `src/shared/i18n/index.ts` 追加：

```ts
import { DEFAULT_THREAD_TITLE } from '../constants'

const GRAPH_NAME_SUFFIXES: { zh: string; key: TranslationKey }[] = [
  { zh: '产品蓝图', key: 'graph.nameSuffix.online' },
  { zh: '开发场景', key: 'graph.nameSuffix.dev' },
]

export function localizeGraphName(name: string): string {
  for (const suffix of GRAPH_NAME_SUFFIXES) {
    if (name.endsWith(` - ${suffix.zh}`)) {
      return `${name.slice(0, name.length - suffix.zh.length)} - ${t(suffix.key)}`
    }
  }
  return name
}

export function threadTitle(title: string): string {
  return title === DEFAULT_THREAD_TITLE ? t('thread.defaultTitle') : title
}
```
